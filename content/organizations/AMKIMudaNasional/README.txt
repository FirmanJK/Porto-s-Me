# Instruksi Menambahkan Logo Organisasi

Untuk menambahkan logo AMKI Muda Nasional:

1. Siapkan logo organisasi (PNG atau JPG dengan background transparan lebih baik)
2. Rename file menjadi: **amki-nasional-logo.png**
3. Simpan di folder ini (sama dengan index.md)
4. Recommended size: 200x200px atau square (1:1 ratio)

Logo akan muncul di sebelah kiri informasi organisasi.
